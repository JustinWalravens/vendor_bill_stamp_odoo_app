PDF Stamp & Nextcloud Sync

Odoo 17 Community Accounting Sales Nextcloud

Automatically stamp your invoices, credit notes and quotations with their Odoo reference number — then push the PDF straight to your Nextcloud, organised by document type and year.

Key Features

✓ Automatic PDF Stamping

Appose the Odoo reference number on every page of the PDF at validation time. Blue text with black outline, fully configurable.

✓ Smart PDF Detection

If a supplier PDF is already attached (e.g. via Peppol), it is stamped directly. Otherwise the Odoo-generated PDF is used as fallback.

✓ Nextcloud Integration

Send every validated document to a configurable Nextcloud folder via WebDAV. Missing folders are created automatically.

✓ Dynamic Path Variables

Use {year}, {month}, {day}, {ref} and {number} in the destination path to organise files by date.

✓ Per-Document-Type Control

Independently enable stamping and Nextcloud sync for: vendor bills, vendor credit notes, customer invoices, customer credit notes, and quotations.

✓ Live Quotation Sync

Every time a quotation is saved, the latest PDF is automatically pushed to Nextcloud — always up to date.

Supported Document Types

  • Vendor Bills (in_invoice)
  • Vendor Credit Notes (in_refund)
  • Customer Invoices (out_invoice)
  • Customer Credit Notes (out_refund)
  • Quotations & Sales Orders (sale.order)

Path Variables Reference

VariableDescriptionExample

Example path: /Invoices/{year}/Suppliers/ → /Invoices/2026/Suppliers/FF-26-3-21.pdf

Configuration

All settings are available in Settings → PDF Stamp (dedicated tab):

  • Enable / disable stamp per document type
  • Text color (hex), font size, position (top/bottom, left/right)
  • Nextcloud URL, username, password / app token
  • One destination path per document type, with variable support

Requirements

  • Odoo 17 Community or Enterprise
  • Python libraries: pypdf, reportlab (install via pip on your server)
  • Nextcloud instance with WebDAV enabled (standard)
  • sale module required for quotation sync
Note: The stamp is applied on top of existing PDF attachments (e.g. Peppol/UBL). The original file is never modified — a new _stamped.pdf attachment is created alongside it.

Tampon PDF & Synchronisation Nextcloud

Odoo 17 Community Comptabilité Ventes Nextcloud

Apposez automatiquement le numéro Odoo sur vos factures, avoirs et devis — puis envoyez le PDF directement dans votre Nextcloud, organisé par type de document et par année.

Fonctionnalités principales

✓ Tampon PDF automatique

Appose le numéro de référence Odoo sur chaque page du PDF à la validation. Texte bleu avec contour noir, entièrement configurable.

✓ Détection intelligente du PDF

Si un PDF fournisseur est déjà joint (ex. via Peppol), c'est lui qui est estampillé. Sinon, le PDF généré par Odoo est utilisé en fallback.

✓ Intégration Nextcloud

Envoie chaque document validé vers un dossier Nextcloud configurable via WebDAV. Les dossiers manquants sont créés automatiquement.

✓ Variables de chemin dynamiques

Utilisez {year}, {month}, {day}, {ref} et {number} dans le chemin de destination pour organiser les fichiers par date.

✓ Contrôle par type de document

Activez indépendamment le tampon et la sync Nextcloud pour : factures fournisseur, avoirs fournisseur, factures client, avoirs client et devis.

✓ Sync devis en temps réel

À chaque sauvegarde d'un devis, le PDF le plus récent est automatiquement envoyé vers Nextcloud — toujours à jour.

Types de documents supportés

  • Factures fournisseurs (in_invoice)
  • Notes de crédit fournisseurs (in_refund)
  • Factures client (out_invoice)
  • Notes de crédit client (out_refund)
  • Devis & commandes client (sale.order)

Configuration

Tous les paramètres sont dans Paramètres → Tampon PDF (onglet dédié) :

  • Activer / désactiver le tampon par type de document
  • Couleur du texte (hex), taille de police, position (haut/bas, gauche/droite)
  • URL Nextcloud, utilisateur, mot de passe / token d'application
  • Un chemin de destination par type de document, avec support des variables

Prérequis

  • Odoo 17 Community ou Enterprise
  • Librairies Python : pypdf, reportlab (à installer via pip sur votre serveur)
  • Instance Nextcloud avec WebDAV activé (standard)
  • Module sale requis pour la sync des devis
Note : Le tampon est appliqué par-dessus les pièces jointes PDF existantes (ex. Peppol/UBL). Le fichier original n'est jamais modifié — une nouvelle pièce jointe _stamped.pdf est créée en parallèle.
